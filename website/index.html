Security

There's no cloud to breach and no account to leak. This is everything a copy passes through between your two devices, and it goes nowhere else.

Your phone
  1. 01

    Pair

    6-digit code

    A fresh ECDH exchange on secp256r1 makes the shared key, and both screens show six digits drawn from it. Confirming they match is what stops anyone sitting in the middle.

    A pairing QR carries a one-time key that expires. After that the peer's key is pinned, and a later swap fails closed.

  2. 02

    Seal

    AES-256-GCM

    Every copy and file is sealed on the device before it leaves, under the key from pairing. GCM is authenticated, so tampering is caught, not hidden.

    Large files are sealed chunk by chunk.

  3. 03

    Travel

    Sealed on every link

    Over your Wi-Fi, or with no network at all: QR, NFC, Wi-Fi Direct and hotspot links each use a per-session key.

    Off-grid sealing needs Android 3.7.3 and Windows 3.7.7. With an older app on either side the link is authenticated but unsealed, so update both.

  4. 04

    Open

    Keys stay home

    Each pairing's keys are generated on your hardware and kept in the OS keystore. Never uploaded, shared or escrowed.

    Unpair a device and its keys are wiped.

How to use

Does it need an internet connection?

No. On the same Wi-Fi it goes direct over your LAN; with no network at all it creates its own link via QR, NFC, Wi-Fi Direct or a hotspot bridge. Your clipboard and files never route through the internet. The app does reach out for one thing, and only if it can: a version check that asks GitHub whether a newer build exists.

Does it use my mobile data?

It only reaches devices on your local Wi-Fi, and that traffic never crosses onto the internet, so it doesn't count against a data plan. It also can't discover devices over cellular. You need the same Wi-Fi, or an off-grid QR or NFC link.

Is my data uploaded anywhere?

Never. There are no servers and no account. Clipboard contents and files move straight between your devices, with keys stored only on your hardware. Those bytes are sealed with AES-256-GCM whether they cross your Wi-Fi or an off-grid QR or NFC link. Off-grid sealing needs Android 3.7.3 or later and Windows 3.7.7 or later on both ends; with an older device the off-grid link is still direct and authenticated, but the file bytes are not sealed.

What is the 6-digit code?

It's a Short Authentication String derived from a secure key exchange. Both devices show the same number, and confirming they match proves you're connected to the right device and not an impostor.

Does copying on my phone sync to my PC by itself?

Not on its own. Since Android 10, apps can't read the clipboard while they're in the background, and OffBridge doesn't try to get around that. What you copy on Windows reaches the phone automatically; to send from the phone, tap the Push to PC quick-settings tile, use Share → OffBridge, or open the app, which sends whatever you last copied.

Which languages does it support?

Both apps ship in English, German, Spanish, French, Indonesian, Japanese, Portuguese, Russian, and Simplified and Traditional Chinese.

How large a file can I send?

Multi-gigabyte transfers are supported, with live per-file progress. If the connection drops mid-transfer it resumes rather than starting over.

How do I install it?

Android installs from Google Play, or as a direct APK from the download section if you'd rather not use Play; the APK usually gets a new release a little before the store does. The Windows version is a standard installer with a bundled runtime, so there's no Java to set up. It isn't code-signed yet, so Windows may flag it the first time; the next question covers what to do.

Windows blocked the installer or can't verify the publisher?

That's Windows reacting to the missing code signature, not to anything the app does. It shows up two ways. SmartScreen displays a blue “unknown publisher” notice you can pass with More info, then Run anyway. Smart App Control, a stricter Windows 11 feature that's switched on for some machines, can block it outright with “couldn't verify the publisher,” and by design it has no per-app override.

OffBridge is off-grid and has no account; it's simply an unsigned indie build with no reputation yet. It does sit in the system tray so it can receive transfers, which is the app doing its job rather than anything hidden. You can confirm any download against the SHA-256 on the Windows card.

Two honest caveats. Smart App Control decides per file hash, so clearing one build does nothing for the next one. And the app is not code-signed yet, so we can't promise a date when a given release stops being flagged. If SmartScreen is all that's in your way, More info then Run anyway gets you through. If Smart App Control is on, there's no per-app override, and we'd rather you skip the install than switch the feature off.
