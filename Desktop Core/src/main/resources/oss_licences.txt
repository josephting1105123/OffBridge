================================================================================
Bundled Java runtime (Windows installer only)
================================================================================

The Windows installer ships a trimmed Java runtime produced by jpackage from
Eclipse Temurin 17 (OpenJDK). It is not in this source tree; it is assembled at
package time and lives under runtime/ inside the installed application.

  Eclipse Temurin / OpenJDK 17    GPLv2 with the Classpath Exception
      The Classpath Exception is what permits linking and shipping the runtime
      alongside an Apache-2.0 application without the GPL reaching this code.
      Full text: https://openjdk.org/legal/gplv2+ce.html

jpackage carries the JDK's own legal/ tree into the runtime image, and the
installer copies the application directory recursively, so the licence texts
ship inside the install at runtime\legal\ (44 files). That is what satisfies
the GPL's requirement to accompany the binary — do not prune that folder to
save space.

This applies to the installer artifact, not to the source distribution.
