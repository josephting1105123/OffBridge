# Audit — 3.5.1 (2026-07-03)

Seven parallel read-only auditors over the tree at `50d141f` (post god-class refactor): Android app (5 scoped sub-audits + consolidation), Windows module, website, and a cross-platform crypto/wire specialist reading both clients side by side.

**Headline verdict:** the overnight TransferDaemon/FileStreamer refactor is **wire-clean** — string-literal and constant diffs against pre-refactor blobs show zero change to frames, key derivation (HKDF infos, ECDH, pv2 PIN), AAD construction, nonces (SecureRandom throughout), MAC comparisons (`MessageDigest.isEqual` throughout), ports, flag-order tolerance, or timeouts. All golden vectors (ClipboardSeal, FileSeal v1/v2, control-plane, PIN-v2) remain byte-identical across platforms. The refactor's only residue is cosmetic (mojibake, BOMs, dead wrappers, scratch files).

Counts: **44 bugs** (fix waves below) · **~60 improvements** (catalogued, not implemented — per run policy).
